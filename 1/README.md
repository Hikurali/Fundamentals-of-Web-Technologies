# Лабораторная работа № 1

Откройте index.html в браузере.

Файлы:
- index.html — главная страница.
- styles.css — стили.
- menu.html — простая страница для ссылки «Меню».
- images/lunch.jpg — изображение.
- .htmlhintrc — правила проверки преподавателя.

Главная страница содержит шапку с h1 и навигацией, три раздела main
(о компании, преимущества, популярные блюда) и footer с контактами.
В списке три преимущества, в таблице пять блюд.
Ссылка «Контакты» ведёт к footer с id="contacts".

Все обязательные свойства CSS использованы. Шрифт Roboto подключён
через Google Fonts. Для его загрузки нужен интернет.
JavaScript в этой лабораторной не требуется.

Компания, цены и телефон приведены как учебный пример.
