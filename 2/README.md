## Что сделано

- Обратная связь: ФИО, email, источник знакомства с компанией, тип обращения,
  сообщение, вложения и согласие на обработку персональных данных.
- Аутентификация: логин, пароль и флажок «Запомнить меня».
- Форма аутентификации находится по центру страницы, на фоне изображения.
- Обе формы отправляют данные методом POST на https://httpbin.org/post.

Для проверки используй вымышленные данные и тестовый пароль:
httpbin показывает все отправленные параметры, включая пароль.
