## Что сделано

- Функция `loadDishes()` получает блюда с помощью `fetch`.
- Используется HTTPS API для сайта на GitHub Pages.
- Ответ сервера преобразуется из JSON в массив объектов.
- Статического массива блюд в работе нет.
- После загрузки блюда сортируются и добавляются на страницу через JavaScript.
- Салаты из API показываются в разделе «Салат или стартер».
- После загрузки работают фильтры, выбор блюд и подсчёт стоимости.
- Проверка состава заказа и уведомления из лабораторной № 6 сохранены.
- Если сервер временно недоступен, на странице выводится сообщение об ошибке.

По просьбе владельца проекта используется собственный API:
`https://82.23.173.175/labs/api/dishes`. Исходники находятся в `server/`.
Общий адрес API задан в `shared/api-config.js`.

Для проверки формы используйте вымышленные данные.
