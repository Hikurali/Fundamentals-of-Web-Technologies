## Что сделано

- В `localStorage` сохраняются только идентификаторы выбранных блюд.
- После обновления страницы выбранные карточки и итоговая стоимость восстанавливаются.
- На странице «Собрать ланч» добавлена липкая панель перехода к оформлению.
- Ссылка на оформление доступна только для правильного комбо.
- Создана отдельная страница `order.html` с составом заказа и формой.
- Блюда можно удалить из заказа, после чего итоговая стоимость пересчитывается.
- Перед отправкой проверяется состав комбо и заполнение обязательных полей.
- Заказ отправляется на API методом `fetch` в формате JSON.
- После успешной отправки заказ удаляется из `localStorage`, при ошибке сохраняется.

Для проверки формы используйте вымышленные данные.
