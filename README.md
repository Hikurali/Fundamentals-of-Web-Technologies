Для просмотра откройте index.html в браузере.

Формы второй лабораторной отправляются методом POST на https://httpbin.org/post.
Этот сервис показывает отправленные параметры. Это учебные формы: используйте
тестовые данные, а не настоящие пароли. Вложения отправляются с помощью
multipart/form-data. Флажок «Запомнить меня» отправляет параметр remember;
реальная авторизация и сохранение сессии в этой работе не реализуются.
