## Что сделано

- На странице показаны пять допустимых вариантов ланча.
- Варианты расположены в сетке по три блока в строке.
- Изображения и подписи внутри каждого варианта расположены с помощью flex.
- При наведении изображения приподнимаются и увеличиваются.
- Десерт вынесен в отдельный блок. Его можно добавить к любому ланчу.
- Перед отправкой скрипт проверяет выбранный состав заказа.
- Если состав не подходит, форма не отправляется и появляется уведомление.
- Реализованы все пять текстов уведомлений из задания.
- Кнопка «Окей» меняет цвет при наведении и закрывает уведомление.
- После успешной проверки форма отправляет все данные методом POST.

Для проверки формы используйте вымышленные данные.
