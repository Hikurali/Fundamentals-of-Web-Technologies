## Что сделано

- Карточек блюд изначально нет в HTML.
- `dishes.js` содержит массив объектов с блюдами.
- `display.js` сортирует блюда по алфавиту и создаёт карточки через DOM.
- У каждой карточки есть атрибут `data-dish` с уникальным `keyword`.
- `order.js` выбирает по одному блюду каждой категории, выделяет карточку,
  показывает выбранные позиции и считает общую стоимость.
- Если заказ пуст, показан текст «Ничего не выбрано».
- Если выбрана только часть заказа, для остальных категорий выводится сообщение,
  что блюдо или напиток не выбран.
- Скрытые поля формы передают на сервер латинские `keyword` выбранных блюд.
- Остальные поля формы также отправляются методом POST на httpbin.org.

Это учебная форма. Для проверки используйте вымышленные данные.
